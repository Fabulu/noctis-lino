( *** fpsched - x87 SCHEDULES AS DATA ***

  One mnemonic per line, in the order the binary has them.  This file is
  the input to tools/genfp.py, which emits fpchains.txt.

  WHY THIS FILE EXISTS AT ALL.  The thing that has to be transcribed from
  NOCTIS.EXE is not the C expression, it is the INSTRUCTION SCHEDULE.  One
  spilled intermediate costs about a quarter of the STARMAP records, so
  where Borland did and did not store is semantics, not an optimisation
  detail.  In a schedule the absence of an fstp is the absence of an fstp -
  there is nothing to re-derive and therefore nothing to get wrong.  An
  fstp followed by an fld of the same slot is how a DELIBERATE spill is
  written down, so a transcription that finds one in the binary can say so.

  Slot mapping, applied in declaration order:
      in int32 ...   -> FJ0 FJ1 FJ2 FJ3
      in f64   ...   -> FA  FB  FC  FD
      out f64  ...   -> FA          (every chain leaves its result in FA)
      const          -> a generated variable, one unit for int32,
                        an adjacent pair for f64 (low half first)
      temp           -> a generated adjacent pair, the spill slot

  Directives: chain, cw, in, out, const, temp, exact, note.
)

chain NsIdentity
  exact
  cw    133F
  note  NOCTIS-0.CPP:4078  nearstar_identity = x/100000*y/100000*z/100000
  note  left associated exactly as C requires: five operations, ONE store
  in    int32 x, y, z
  out   f64   id
  const K100000 = int32 100000
  fild  x
  fidiv K100000
  fild  y
  fmulp
  fidiv K100000
  fild  z
  fmulp
  fidiv K100000
  fstp  id
end

( ==================================================================== )
( A SECOND, DIFFERENT-SHAPED CHAIN, to prove the generator is a         )
( generator and not one hard-coded routine wearing a costume.  This is  )
( the shape a seedval product has: repeated multiply of doubles that    )
( are already on the stack, with no store until the end.                )
( ==================================================================== )

chain Prod4
  exact
  cw    133F
  note  FA*FB*FC*FD left associated, four doubles, three multiplies,
  note  ONE store.  The scalar route would round three extra times.
  in    f64 a, b, c, d
  out   f64 p
  fld   a
  fld   b
  fmulp
  fld   c
  fmulp
  fld   d
  fmulp
  fstp  p
end
