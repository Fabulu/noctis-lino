
      ( *** mul64frag - 32x32 -> 64 multiply via inline x86 machine language *** )

      ( One of three interchangeable backends behind the same two entry points:

            "Mul64u"   [m64a] * [m64b] -> [m64lo], [m64hi]   unsigned
            "Mul64s"   [m64a] * [m64b] -> [m64lo], [m64hi]   signed

        Operands and results are passed in memory, not in registers, because
        the fragment below clobbers edx invisibly to the compiler and the
        limb backend needs more scratch than there are registers. A caller
        that only has to remember "destroys A, B, C, D" can swap backends
        without reading any of them.

        The two entry points are deliberately SEPARATE rather than one
        routine with a sign flag. sky/isthere are imul; fast_random is mul.
        A single routine that guessed wrong would build a complete, plausible
        and entirely wrong universe with no diagnostic anywhere.

        This backend needs the STOCK compiler and the STOCK i386 pack. It is
        the only one of the three that does, which is why it is the one the
        port can currently ship: main/lib/gen/compiler.txt is under a licence
        that forbids modification, so a patched compiler is not ours to
        redistribute.                                                        )

"variables"

	m64a	= 0;
	m64b	= 0;
	m64lo	= 0;
	m64hi	= 0;

"programme"

"Mul64u"
    ( Unsigned 32x32 -> 64.  In: [m64a],[m64b].  Out: [m64lo],[m64hi].  )
    ( Destroys A, B, D.  D is written by the fragment, not by the       )
    ( compiler, so never place this call where D is live.               )

	A = [m64a];
	B = [m64b];
	{
	    F7 E3	(mul ebx  ->  edx:eax = eax * ebx, UNSIGNED)
	}
	[m64hi] = D;	( store the invisible register first )
	[m64lo] = A;

	end;

"Mul64s"
    ( Signed 32x32 -> 64.  Same contract as Mul64u. )

	A = [m64a];
	B = [m64b];
	{
	    F7 EB	(imul ebx  ->  edx:eax = eax * ebx, SIGNED)
	}
	[m64hi] = D;
	[m64lo] = A;

	end;
