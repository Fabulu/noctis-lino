      ( *** suseed - Wave 7a float primitives, __ftol, the two fast_srand
	    bridges and the secs arithmetic ***

	This is a LIBRARY.  It owns every floating-point operation that
	surface() performs, and it owns them as WHOLE EXPRESSIONS rather
	than as a sequence of scalar operations, because Borland's 8087
	code stores an intermediate only where the C declares a variable.
	Wave 3 measured what a single spurious store costs: 1,050 of 4,113
	catalogue records.  fp/fpx87's FAdd/FMul are correct for a site
	where the original also stored; they are wrong for a generation
	expression, and every expression below is a generation expression.

	THE CONTROL WORD is fp/fpabi's FCWEXT, 133Fh: PC = 64 bits, RC =
	round to nearest.  FEnter installs it.  Two places need something
	else and both build it explicitly:

	  __ftol.  A C cast truncates.  Borland flips RC to chop, does the
	  fistp, flips back.  [SUcwc] is 1F3Fh and [SUcwn] is 133Fh, and
	  the pair is loaded around the store.

	  fistp qword, NOT fistp dword.  NOCTIS-0.CPP:4890 computes
	  (long)(10*secs) where secs is around 5.05e8, so the value is
	  5.05e9 and does NOT fit in an int32.  Borland's __ftol stores 64
	  bits and returns the low 32, wrapping silently.  fistp dword
	  would raise a masked invalid-operation and store 80000000h for
	  every one of them, which is not the same universe.  That is why
	  "SU chop32" ends in DF BF (fistp qword) and reads back only the
	  low unit.

	  Measured consequence, so the wrap is not theoretical: with the
	  guest clock pinned to 2000-01-01 12:00:00, secs is about
	  504,964,800.  10*secs = 5,049,648,000 wraps to 754,680,704 and
	  60*secs = 30,297,888,000 wraps to 233,116,928.  Types 2, 5 and 6
	  divide those wrapped values.

	THE FLOAT-32 GLOBAL.  NOCTIS-0.CPP:4443 declares "float a", and
	four painters loop "for (a=0; a<2*M_PI; a+=4*deg)".  That loop
	runs NINETY times, not ninety-one, and the only reason is that "a"
	is a binary32 in memory and is round-tripped through it on every
	iteration.  [SFa] is therefore a 32-bit unit holding a binary32
	BIT PATTERN, every read of it is "fld dword", and every write is
	"fstp dword".  Keeping the angle in a double or in an x87 register
	produces 91 iterations and a different planet.

	COMPARISONS ARE DONE IN BINARY32, ON PURPOSE.  "a < 2*M_PI"
	compares a binary32 against a binary64.  There is no binary32
	strictly between 2*M_PI and (float)2*M_PI, so comparing against
	(float)2*M_PI gives the same answer for every possible "a",
	including equality.  The same argument settles 359, 0, 63 and 179
	exactly, since all four are representable.  So L.in.oleum's own
	"??" directives - which are fld dword / fcom - are used, and no
	fragment is needed for a comparison.

	NAMING: no symbol here may contain div, plus, minus, multiplied,
	pragma, mtp, relating or asbytesize.  "K4DEG0" is a slot, not a
	number: the PATTERNS are constants and "SU fp init" copies them
	into variables, because an ML fragment can only address a variable
	and a constant has no address.                                    )
